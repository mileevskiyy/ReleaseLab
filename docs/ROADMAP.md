# Future work

These are unimplemented extensions, not current capabilities.

- Authenticated operators, service permissions and independent multi-person approval.
- Signed CI/webhook evidence with provenance validation and replay protection.
- Registry verification that binds manifests to actual image digests and build artifacts.
- Pluggable deployment adapters with explicit authorization, health probes and provider failure handling.
- Separate durable job execution, leases and coordinated per-environment locks for multiple workers.
- Migration analysis and compatibility checks based on actual schemas rather than declarations.
- Service-specific policies, maintenance windows and approval workflows.
- Durable accounts, export/import policy, accessibility/security reviews and measured load limits.
